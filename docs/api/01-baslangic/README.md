# Başlangıç Rehberleri

[API dokümantasyonuna dön](../README.md)

API ile ilk entegrasyon için rehberleri aşağıdaki sırayla okuyun:

1. [Hızlı başlangıç](01-hizli-baslangic.md): ilk isteği gönderme ve temel ortam bilgileri
2. [Kimlik doğrulama ve yetkilendirme](02-kimlik-dogrulama-ve-yetkilendirme.md): Public, User, Admin, Guest ve Provider erişimleri
3. [Ortak kurallar](03-ortak-kurallar.md): tarih, sayfalama, içerik tipi ve ortak response yapıları
4. [Hatalar ve güvenli tekrar](04-hatalar-ve-guvenli-tekrar.md): ProblemDetails, idempotency, concurrency ve retry kararları
5. [Kimlikler ve enumlar](05-kimlikler-ve-enumlar.md): UUID, public ID ve sayısal enum sözleşmeleri
