# GET /api/alt-banner-3

- Görev alanı: **Mağaza ve iletişim → Bannerlar → Alt banner 3**.

- Yetki: **Public**.
- İşlev: Alt Banner 3 bölümünün en fazla 5 aktif medyasını `displayOrder` sırasıyla döndürür.
- Response: `BannerSectionDto`; `name=Alt Banner 3`, `key=alt-banner-3`.

Alanlar için [ortak banner bölüm sözleşmesine](../ortak-sozlesme.md) bakın.
