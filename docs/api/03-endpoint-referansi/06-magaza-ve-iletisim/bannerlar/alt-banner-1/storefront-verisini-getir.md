# GET /api/alt-banner-1

- Görev alanı: **Mağaza ve iletişim → Bannerlar → Alt banner 1**.

- Yetki: **Public**.
- İşlev: Alt Banner 1 bölümünün en fazla 5 aktif medyasını `displayOrder` sırasıyla döndürür.
- Response: `BannerSectionDto`; `name=Alt Banner 1`, `key=alt-banner-1`.

Alanlar için [ortak banner bölüm sözleşmesine](../ortak-sozlesme.md) bakın.
