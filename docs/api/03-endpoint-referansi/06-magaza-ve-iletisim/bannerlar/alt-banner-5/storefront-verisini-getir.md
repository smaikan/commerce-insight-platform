# GET /api/alt-banner-5

- Görev alanı: **Mağaza ve iletişim → Bannerlar → Alt banner 5**.

- Yetki: **Public**.
- İşlev: Alt Banner 5 bölümünün en fazla 5 aktif medyasını `displayOrder` sırasıyla döndürür.
- Response: `BannerSectionDto`; `name=Alt Banner 5`, `key=alt-banner-5`.

Alanlar için [ortak banner bölüm sözleşmesine](../ortak-sozlesme.md) bakın.
